# Codelin 界面规范

界面采用 Apple 风格的清晰层级、系统排版、充足留白和克制的功能性装饰。以安静、专注和可控为目标。

- 字体使用系统字体栈：Apple 平台优先系统字体，Windows 使用 Segoe UI，中文使用系统中文字体；代码使用等宽字体。
- 浅色主背景 `#ffffff`，侧栏和次级表面 `#f5f5f7`，正文 `#1d1d1f`，次级文字 `#64646b`。蓝色按钮 `#0071e3` 为主要强调色。深色模式提供独立颜色变量。
- 间距、圆角、阴影使用 Tailwind 默认尺度。标题使用平衡换行，正文使用自然换行，时长等数字使用等宽数字。
- 工作台保持稳定的侧栏、标题区、消息区和输入区；宽屏消息有阅读宽度上限，手机侧栏转为可关闭的无障碍对话框。
- 不使用装饰性渐变、发光或循环动画。交互状态立即响应，减少动态效果和提高对比度的系统偏好得到尊重。
- 图标使用同一图标库。所有仅图标按钮有可访问名称；模态对话框使用 Radix 处理焦点、Escape 和焦点恢复。
- 删除操作通过 AlertDialog 确认。加载使用结构占位，错误保留在触发操作附近；部分回复不会因断线而丢失。
- 示例内容明确标注为演示。无后端接口的功能不提供虚假按钮，审批与执行记录展示后端实际返回内容。
