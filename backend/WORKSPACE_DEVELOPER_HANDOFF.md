# 工作区与对话新版交接

本版直接重建数据库，不兼容旧数据，不保留业务迁移机制。启动方式与接口契约见 WORKSPACE_API.md 和项目 README。

## 数据归属

用户拥有多个工作区、多个对话。对话 workspace_id 可空；复合外键确保对话与工作区同属一个用户。消息和工具记录随对话删除，代码块随工作区删除。同一工作区中的对话共享 pgvector 与 BM25 检索数据。

对话可独立新建，也可在工作区内新建。独立对话可以单向加入工作区，已经加入后不能移出或转入另一工作区。项目路径只保存于工作区，工具使用后端注入的根目录。

## 自动关联

LangGraph 在 agent 与审批/执行之间增加工作区准备节点。纯回答不进入该节点；有效项目工具调用才分配工作区。创建目录、保存工作区和绑定对话由生命周期模块集中处理，失败回滚并移除新目录；流通过 workspace_created 通知前端。准备失败时补上工具失败观察，后续重试不会留下未回答的工具调用。

每轮请求从数据库获取对话归属。审批恢复保持 checkpoint，但先验证对话及工作区仍有效。删除对话同步调用 checkpointer 的 adelete_thread；不保留无法访问的旧状态。

## 并发与删除

Redis 提供会话排他锁、工作区共享/排他锁，60 秒租约每 15 秒续期。聊天和文件访问持工作区共享锁，删除持排他锁；冲突返回 409，Redis 不可用返回 503。流、取消及异常路径均释放租约，不能覆盖其他持有者的锁。取消异步调用时先等待已经开始的线程操作结束，避免文件操作仍在执行时释放保护。

删除先保存 deleting 状态，随后清理目录、checkpoint 和业务记录。失败保留删除标记和可重试入口，暂停新操作；重试对已清理资源幂等。目录删除校验后端根目录和目标归属，拒绝盘符根、源码目录、越界路径及链接根。已有备份不受重建影响。

## 前端

ConversationNav 展示工作区分组及独立对话。App 管理归属、重命名、加入、删除和 SSE。文件浏览与对话归属分别管理；浏览其他工作区不会改变 agent 根目录。清理被删除工作区的标签、草稿、聊天缓存与标题/归属查询，迟到的文件响应不会重新创建已删除标签。

## 验证

后端使用临时 SQLite、内存 checkpoint 和替代模型覆盖业务行为；真实 PostgreSQL 验证复合外键、向量检索和状态删除，真实 Redis 验证共享锁、排他锁和跨进程冲突。前端执行生产构建、SSE 单元测试和浏览器验收，覆盖分组、单向加入、自动创建与遗漏事件恢复、删除重试、移动端和无障碍。

执行破坏性重建前必须停止旧后端，并仅对配置所指的 Codelin 数据库对象与工作区目录操作。正常启动绝不清空数据。
